Live Engine View

The editor's own viewport is a close match to the game, but it is not the game's renderer. The live engine view shows your effect drawn by Petroglyph's engine itself, and updates a moment after each edit. It runs your own copy of the EAW Terrain Editor (the official map editor) in the background as a render host, with a small add-on called Alamo Preview.

Setting it up takes a few minutes and is done once. The Particle Editor's setup never changes your game install.

What You Need

  • Windows and Star Wars: Empire at War — Forces of Corruption, with the editor already finding your game install (see Setup).
  • The 64-bit EAW Terrain Editor. It needs files that only Petroglyph's map editor installer provides. From Petroglyph's mod tools page:
    1. Download and run FOCMapEditor.msi. When it asks for a folder, choose the game's Forces of Corruption folder: on Steam, Star Wars Empire at War\corruption. It adds the map editor tools there.
    2. Download EAW_Terrain_Editor_b.zip and extract its EAW Terrain Editor.exe into that same folder, replacing the one the installer added.
    If setup says the map editor's folder is missing a file, the editor isn't in the folder where the installer put its tools. > The EAW Terrain Editor.exe that comes with the game in GameData is an older 32-bit build > and will not work. Use the one from the mod tools page.
  • Disk space. Setup makes a private copy of the game's Data folder. If the game is on the same drive as your Windows user folder, the copy shares the game's files and takes almost no space. On a different drive it is a full copy of about 1.5 GB.

Set It Up

  1. Open Edit → Preferences… and find the Engine preview section.
  2. Click Set up.
  3. Next to Map editor, click Browse and choose the EAW Terrain Editor.exe you extracted.
  4. Click Set up. A progress bar shows each stage. You can close the dialog; setup keeps going and the Preferences section shows Setting up until it is done. Press Cancel to stop setup and remove its partial copy. Closing the Particle Editor also cancels setup.

When it finishes, the dialog shows Setup complete and the path of the new copy, and the Map editor executable field is filled in for you. The copy lives in your user folder, under %LOCALAPPDATA%\AloParticleEditor\EngineHost. If your Windows user folder has non-English characters, the copy goes under %ProgramData%\AloParticleEditor\EngineHost instead, in a private folder for your Windows account.

Updating

After installing a newer Particle Editor, Preferences → Engine preview may say the setup's engine host doesn't match the bundled version. Press Refresh setup to update the private copy without choosing the map editor again or recopying game data.

Use It

With an effect open, choose View → Live engine view. The first start takes several seconds while the map editor loads; a badge on the viewport shows Starting engine view…, then the frame rate once frames arrive. From then on, each edit appears in the engine view shortly after you make it, and the engine view follows the editor's camera and ground texture. Choose View → Live engine view again to turn it off.

What It Doesn't Mirror

  • Hiding the ground. The engine view always draws its ground, even when the editor's ground is hidden.
  • Ground height. The engine's ground stays at its own height, so an effect that sits on or below the editor's raised or lowered ground can look cut off differently.

Remove It

In Edit → Preferences… → Engine preview, click Remove setup (it appears once setup has run), then Confirm remove. This deletes only the files setup created, and clears the map editor path if it points to that copy. If the copy shares files with your game install, removing it only removes the copy's names for them; your game files stay as they are.

If Something Goes Wrong

  • "This EAW Terrain Editor build isn't supported" — the chosen EAW Terrain Editor.exe is not the 64-bit build this version of Alamo Preview supports. Download it again from the mod tools page and choose that copy.
  • "The bundled engine-host folder is missing or damaged", "The host package file failed SHA-256 verification" or "The host package is missing …" — the bundled engine-host folder is missing or damaged. Re-extract the Particle Editor release zip into an empty folder. A damaged package can also show a manifest parsing error in Preferences; Remove setup still works.
  • "Engine preview setup requires a Forces of Corruption root (corruption) in the game paths." — the editor's game paths don't include your Forces of Corruption corruption folder, so it has not found your install. Fix that first; see Setup.
  • "The managed engine host folder is not empty. Remove its previous setup first." — an earlier setup is still there. Click Remove setup and try again.
  • "This setup didn't finish. Remove setup and set up again." — setup was interrupted. Click Remove setup, then set up again; Refresh setup is unavailable for an incomplete copy.
  • A map editor is running from the setup folder. The Particle Editor closes its own map editor when you press Set up, Refresh setup or Remove setup. If a map editor you started yourself is running from the setup folder, close it (Task Manager, EAW Terrain Editor) and try again.
  • The engine view stops and the badge says it closed. The editor falls back to its own view. Turn the live engine view on again; if it keeps closing, remove the setup and set it up again.
