# particle-editor

# About
Editor for GlyphX's particle systems


This is entirely based off of Mike.NL's work, with edits made by Claude for quality of life features and attempts to fix bugs. See the original repo here: https://github.com/GlyphXTools/particle-editor

# Download a release
Grab the latest release `.zip`, unzip it anywhere, and run
`x64\Release\ParticleEditor.exe`. The required `d3dx9_43.dll` ships **bundled**
next to the executable, so there is no separate DirectX runtime to install — just
unzip and run.

# Usage
Launch the executable — it opens the WebView2/React UI. This is the only UI
(x64 only); the legacy Win32 chrome and its `--legacy` / `--legacy-ui` opt-out
were removed in.
