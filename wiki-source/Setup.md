# Setup

This page covers the small amount of setup needed for the tutorial course.

The editor automatically locates the game install and mod folders. For the tutorials, create a
simple mod folder that mirrors the game's `DATA` paths:

```text
corruption\Mods\ParticleTutorial\Data\Art\Models\
```

You will also need a way to extract shipped particle files from the game's `.meg` archives. Use MEG
Editor for that external extraction step.
